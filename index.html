よくある質問

効果があるのかよく分かりません

そう感じるのが正常です。Paperstyle は「オンにしていることを忘れる程度」の強さになるよう設計しています。模様がはっきり見えたら強すぎます。

違いを確かめたいときは、⌃⇧P でオンとオフを何度か切り替えてみてください。強度スライダーを一度いちばん右まで動かしてから戻すと、何が変わっているのかが分かりやすくなります。

スクリーンショットに効果が写りません

意図した動作です。重ねている層は、スクリーンショット・画面収録・画面共有のいずれにも含まれません。自分の見え方の設定が、共有する画面や提出する画像に混ざらないようにしています。

Mission Control を開くと元の画面に戻ります

macOS の制約です。Mission Control の上に層を重ねる手段が用意されていないため、開いている間は素の画面が見えます。閉じればすぐ戻ります。

ログインした直後は効いていないようです

「ログイン時に開く」を有効にしていても、ログイン項目の起動は他のサービスと順番待ちになります。起動直後の混み合った状態では、紙面が乗るまで1〜2分かかることがあります。

メニューバーの色も変わります

意図した動作です。画面全体を一様に覆う設計にしているため、メニューバーも対象になります。クリックはそのまま通るので、メニューバーの操作は妨げません。

Space を切り替えた直後に一瞬遅れます

0.3秒ほど遅れることがあります。macOS が公開している範囲での上限で、これ以上速くする手段がありません。

メニューをキーボードだけで操作できません

現在の制約です。メニューのなかのスイッチ・紙面・スライダーには、キーボードだけでは到達できません。オン・オフは ⌃⇧P で切り替えられます。VoiceOver からはすべて操作できます。

ディスプレイを複数つないでいます

接続しているすべてのディスプレイに同じ設定で乗ります。ケーブルを差し直した直後は、認識が終わるまで数秒かかることがあります。

返金してほしい

購入は Apple を通じて行われているため、返金も Apple にご依頼ください。reportaproblem.apple.com から手続きできます。合わなかった理由を教えていただけると、今後の参考になります。

不具合を見つけた / 要望があります

上のアドレスまでお送りください。お使いの macOS のバージョン、Mac の機種、ディスプレイの構成を書いていただけると助かります。

Frequently asked questions

I can't really tell whether it is doing anything

That is the intended result. Paperstyle is designed to be weak enough that you forget it is on. If you can clearly see a pattern, it is too strong.

To see the difference, press ⌃⇧P a few times to toggle it. Dragging the intensity slider all the way to the right and back also makes it easier to notice what is changing.

The effect does not show up in screenshots

This is deliberate. The layer Paperstyle draws is excluded from screenshots, screen recordings and screen sharing, so how you prefer to see your screen does not leak into a shared screen or a submitted image.

Opening Mission Control shows the plain screen

This is a macOS limitation. There is no supported way to draw above Mission Control, so the plain screen shows while it is open. It returns as soon as you close it.

Nothing happens for a while after I log in

Even with Open at Login enabled, login items start in turn alongside other services. On a busy login it can take one to two minutes before the surface appears.

The menu bar changes colour too

This is intended. Paperstyle covers the whole display evenly, and that includes the menu bar. Clicks pass straight through, so nothing in the menu bar stops working.

There is a short delay after switching Spaces

About 0.3 seconds. This is the limit of what macOS exposes publicly, and there is no supported way to make it faster.

I can't reach the menu controls with the keyboard

This is a current limitation. The switch, the surfaces and the slider inside the menu cannot be reached by keyboard alone. ⌃⇧P toggles the effect, and everything is operable with VoiceOver.

I use more than one display

All connected displays get the same setting. After reconnecting a cable it can take a few seconds for the surface to return.

I would like a refund

Purchases go through Apple, so refunds are handled by Apple at reportaproblem.apple.com. If you have a moment, it helps to know what did not work for you.

I found a bug, or I have a request

Please write to the address above. Your macOS version, Mac model and display setup are all useful to include.
